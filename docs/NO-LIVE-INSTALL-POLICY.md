# Validation scope selected by owner

The owner does **not** want a live installation test. This release uses offline syntax checks, source inspection, route smoke tests, and static integration checks only. The absence of fresh-hardware testing should be disclosed in the project README, not presented as an unresolved requirement for the owner to perform.

The installation guide provides directions for other users, but no live setup or automated deployment was run as part of this publication preparation. Changes to actual Pi services, Synology NAS, and GitHub `main` are explicitly out of scope for candidate validation.
