VinylPi

VinylPi is a personal, open-source music and smart-display project built around a Raspberry Pi. Its optional Google integrations connect privately operated displays and music-playlist tools to the account holder's Google services.

Google Calendar integration

With the account holder's permission, VinylPi reads selected Google Calendars to show upcoming events on the account holder's e-paper display and TV launcher. The integration may use event titles, times, calendar labels, locations and meeting details for display and optional drive-time estimates. It does not create, modify or delete events.

Music Bridge and YouTube

Music Bridge is a personal playlist tool. With the account holder's authorization, it can search YouTube for tracks or music videos and create or update playlists in the authorized YouTube account. It may store playlist IDs, track matches, job status and authorization data locally so paused or quota-delayed jobs can resume. Playlist changes occur only in response to account-holder requests.

These features use separate Google Cloud OAuth applications but share this public project-information site and privacy policy.

This website is informational only. It does not publish private calendar entries, playlist histories, device addresses, authentication keys or access to the Raspberry Pi.
